This is a fork of [BrunoLevy/geogram](https://github.com/BrunoLevy/geogram) meant to generate binary `vorpalite` releases for use with [GIBBON](https://github.com/gibbonCode/gibbon).

The default orphan branch contains a single action (triggered manually) that will fetch and build a given tag directly from the original repository, so it's not important (other than for "backup" purposes) to keep `main` up to date with the original repository.
